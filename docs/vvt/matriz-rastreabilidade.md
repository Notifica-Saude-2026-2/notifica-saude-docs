## 1. Introdução { #introducao }

Relação entre as histórias de usuário (e seus critérios de aceite), os requisitos não-funcionais e os casos de teste que os validam, gerada a partir das informações de identificação de cada caso de teste do documento [Casos de Teste](casos-de-teste.md). As histórias e critérios seguem a numeração registrada nos casos de teste.

!!! note "Manutenção"
    Ao incluir, alterar ou remover um caso de teste no documento de Casos de Teste, atualize também as tabelas abaixo.
